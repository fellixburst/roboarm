# M1 实现与验收说明

更新日期：2026 年 11 月 4 日。本实现只运行模拟设备。模拟验收通过仅代表 M1 完成，不代表 SO101、底盘、视觉或物理急停已通过真机测试。

## 技术选型

使用 Node.js 24.22.1 的原生 HTTP 服务和 `worker_threads`；网页采用原生 HTML、CSS 与 JavaScript，无构建步骤，Three.js 0.180.0 为新增三维渲染依赖。一个服务同时提供网页、控制 API 与相机与本地 Three.js 模块资源，保持部署简单。独立模拟线程用于隔离设备更新与看门狗，后续真机驱动须复用统一校验入口和设备适配接口。

测试使用 Node.js 内置 `node:test` 与 Playwright 1.56.1，`package-lock.json` 锁定开发依赖。CI 在 Node.js 24.22.1 上运行静态检查、服务测试和 Chromium 交互测试。

## 启动与配置

按根目录 [README](../README.md) 安装后运行 `npm start`。默认地址为 `http://127.0.0.1:3000`；`HOST` 和 `PORT` 可通过进程环境或根目录 `.env` 设置，参考 `.env.example`。模拟运行不使用任何生产密钥。`.env` 不进入版本管理。

云端本机地址需通过平台已有的端口转发或 SSH 隧道访问。本仓库不会自动生成公网预览域名，也尚未实现公网托管及真实设备远程接入。

当前状态保存在内存中。重启服务后设备回到初始禁用状态，所有旧会话和旧控制权失效；日志、抓图列表和位置不会跨服务重启保留。M1 面向本机或受控云预览，不提供生产认证、用户管理与互联网真机接入。

## 控制与停止机制

设备初始禁用，先获取互斥控制权，再显式启用。机械臂关节、夹爪和笛卡尔直线目标受模拟限位与限速约束；坐标路径在运动前经过整段可达性、解析极值和逆运动学检查。小车只接受持续有效的按住意图。停止会清零小车速度、终止未完成的机械臂目标，并保持禁用，后续必须重新启用。

浏览器在松手、指针取消、失去捕获、窗口失焦、页面隐藏或退出时停止续发并尝试发送停止请求。发生请求失败或状态过期时，丢弃当前运动意图，不缓存离线运动命令。重新连接创建新会话，再获取控制权和启用。

控制服务检查会话、互斥控制权、递增序号、重复命令标识与有效期，并持续监视会话存活。模拟设备线程独立使用单调时钟检查租约和驾驶意图超时。即使浏览器无法发送停止请求，或控制服务停止续约，设备看门狗也会停止并禁用。独立线程不等同于独立硬件安全控制器，真实设备需要 M2 现场设计与验证。

命令携带协议版本、设备、会话、命令标识、序号、时钟令牌、有效期、动作和参数。时钟令牌由接收服务发行，有效期在服务自身单调时间上计算；设备线程继续检查接收时已确定的截止期限，排队不能延长有效期。界面的年月日时间仅用于展示，不参与跨主机命令有效性比较。

实际命令格式、动作参数和错误码见 [协议说明](../protocol/README.md)。运行中的时限如下；服务常量位于 `protocol/validation.js`，模拟限制位于 `agents/device/config.json`，这些限制不是 SO101 标定结果。

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| 浏览器心跳间隔 | 250 ms | 刷新会话、时钟令牌与控制租约 |
| 控制租约 | 1200 ms | 服务与设备独立检查续约 |
| 会话过期 | 1800 ms | 拒绝旧会话命令并撤销控制权 |
| 页面状态新鲜度 | 1500 ms | 过期显示失联并禁用操作 |
| 时钟令牌窗口 | 1000 ms | 命令 TTL 必须在 1–1000 ms 内 |
| 小车运动意图看门狗 | 450 ms | 未续发驾驶意图即停车并禁用 |
| 模拟线程更新间隔 | 50 ms | 积分运动并独立检查超时 |
| 小车线速度上限 | 0.3 m/s | 前进或后退 |
| 小车角速度上限 | 0.8 rad/s | 左转或右转 |

关节位置与点动使用度（°），速度使用度每秒（°/s）；关节限位和初始位置逐关节配置。夹爪开度为 0–100%，仅代表模拟开度。小车位置使用米，航向使用弧度。

## 画面与状态

双目相机提供带水印的左图、右图和深度图，通过共享帧号取得同一时刻的合成场景；暂停、恢复、曝光设置和抓图均通过独立视觉通道执行，不参与运动命令传输。图像限制为 2 FPS，缓存最多 6 帧；过期帧明确拒绝。目标框、视差和深度是已知几何场景的合成真值，不是识别模型或真实双目测量。

预览图像的加载、失败和失联状态独立显示，服务返回了元数据不代表画面已经显示成功。末端 XYZ、连杆姿态和坐标轴来自设备返回的同一正运动学模型。双轴云台只预留水平和俯仰能力，保持未配置、未连接状态，不能启用。接口、模型限制和待补充的硬件资料见 [坐标、双目与云台说明](EXTENSIONS.md)。

网页持续显示设备连接、模拟标记、故障、控制者、启用状态和最近更新时间。过期状态显示为失联，不能继续操作。命令历史显示接收、执行与终态；拒绝原因和断线事件写入日志。服务不会将“请求已接收”显示为“动作已完成”。

## 3D 场景扩展

`apps/web/scene3d.js` 使用本地 Three.js 0.180.0。机器人基座 X/Y/Z 映射到场景 X/−Z/Y，统一毫米到米的单位换算；连杆与末端由服务端 `linkPointsMm` 驱动，夹爪使用开度和滚转反馈，小车使用 `pose`。两类设备独立放置，保持原坐标基准。视角操作不创建设备命令；不预测离线运动。轨迹各最多 200 点，隐藏页面暂停绘制，GPU 上下文丢失提示刷新，3D 模块失败不阻塞控制。

本扩展只可视化现有手动流程，不添加自动导航、抓取、碰撞求解或相机外参。

三维扩展验收：原 59 项服务与设备测试通过；15 项 Chromium 测试通过，新增三维 FK/夹爪反馈、运动位姿同步、视角不触发命令、资源失败回退和过期提示四项浏览器场景。WebGL 测试使用 SwiftShader 软件渲染，不需要 GPU。

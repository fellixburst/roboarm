# 云端开发任务书

## 开发目标

请依据 README.md、PROJECT_BRIEF.md 和 ROADMAP.md，实现 M1：机械臂与小车网页控制平台的模拟版本。界面使用中文，能在没有机械臂、串口、摄像头和 GPU 的云端环境运行。

## 交付要求

交付可启动的网页、控制服务和模拟设备，不只交付界面截图。用户必须能够切换模拟机械臂和小车，发出操作并看到服务端产生的状态反馈。所有模拟状态有清晰标记；禁止将模拟连接显示成真实硬件连接。

技术选型在实施时结合云端环境确定并记录理由，锁定实际依赖版本。建议保持单仓库，将网页、服务、设备适配器、协议、测试和文档分开；不为第一版引入无实际需要的分布式部署。

建议代码目录：

```text
apps/web/             中文网页控制台
services/control/     会话、控制权、命令和状态服务
agents/device/        模拟驱动及后续真机驱动
protocol/             协议定义与示例
tests/                协议和关键控制行为测试
docs/                 需求、部署和现场验收记录
```

以上为拟定目录，当前尚未创建这些应用模块。

## 实现约束

1. 提供设备适配接口，模拟驱动和真机驱动走同一命令校验入口；第一版只启用模拟驱动。
2. 命令包含协议版本、设备标识、会话标识、命令标识、递增序号、有效期和参数。定义单位、重复处理和错误码。
3. 跨主机不得直接比较未同步的本地时钟。有效期校验需定义发送端与接收端时间基准；设备侧使用单调时钟管理心跳和控制租约。
4. 设备默认未启用；控制权互斥；过期、乱序、重复、越界和无控制权的运动命令不得导致重复运动。
5. 小车按住操作，松手停止；页面失焦、连接丢失和会话过期有对应停止路径。服务端和设备端独立监视，不能只依赖浏览器发停止请求。
6. 停止后需要显式重新启用；重连不能回放离线期间积压的运动指令。
7. UI 显示命令真实生命周期和状态更新时间；过期状态标为失联，不能继续显示正常在线。
8. 视频使用独立通道或资源限制，不能堵塞控制。第一版可使用明确标注的模拟视频画面。
9. 密钥从环境配置读取，仓库只提供示例配置；模拟模式不需要生产密钥。

## 必须验证的行为

- 从干净环境按 README 成功启动模拟版。
- 一次机械臂操作和一次小车操作都有可见反馈与日志。
- 越界命令被拒绝，不修改设备位置。
- 松手、断线、租约过期后小车停止。
- 重复命令不重复执行，过期与旧会话命令被拒绝。
- 两个浏览器会话不能同时控制同一设备。
- 停止及重连后不自动恢复运动。
- 未连接硬件时不显示真机运行成功。

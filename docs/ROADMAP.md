## 阶段与验收

| 阶段 | 交付 | 验收条件 |
| --- | --- | --- |
| M0 项目建档 | GitHub 仓库、需求、任务看板 | 文档可读取，任务有验收标准 |
| M1 云端模拟控制台 | 中文网页、控制服务、模拟设备 | 无 USB 硬件可启动；机械臂和小车有反馈；断线及停止行为可测试 |
| M2 桌面 SO101 接入 | 真实适配器、标定配置、相机预览 | 在现场低速操作单关节和夹爪；超限拒绝；反馈能与实物对应 |
| M3 小车无线遥控 | 车载代理、底盘适配器、无线视频 | 松手与失联停车；重连不恢复旧动作；控制不被视频阻塞 |
| M4 桌面视觉抓取 | 固定相机、目标定位、抓取流程 | 在定义好的场景重复测试，记录成功次数、总次数和失败原因 |
| M5 移动抓取 | 小车与机械臂协同任务 | 先停车再抓取；记录目标发现、接近、抓取与放置的独立结果 |
| M6 扩展 | 云台、示教、学习策略、远程访问 | 每个扩展单独定义场景和验收，不影响基本手动控制 |

阶段按验收推进，暂不承诺缺乏硬件与工时依据的日期。
